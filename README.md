JavaScript Cookbook — Practice

My solutions and experiments while working through the JavaScript Cookbook (O'Reilly).

I am a QA engineer moving into test automation. I use this repository to build a strong JavaScript base for automation work with Playwright. Each folder matches a chapter of the book and contains the examples I wrote and ran myself.

Structure
Folder	Topic
SettingUpDevEnv/	Setting up the development environment: browser developer console, logs and errors

More chapters will be added as I go through the book.

How to run the examples

Most examples are plain HTML + JavaScript files. No build step is needed.

Clone the repository:
bash
   git clone https://github.com/OksanaGryshyna27/JavaScriptCookbook.git
Open an .html file in the browser (or use the Live Server extension in VS Code).
Open the developer console to see the output:
Chrome / Edge: Cmd+Option+J (macOS) or Ctrl+Shift+J (Windows)
Some examples contain errors on purpose to show how they look in the console. These places are marked with a comment in the code.
